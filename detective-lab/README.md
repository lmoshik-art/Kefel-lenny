# הכנה למבחן במדעים, כיתה ז׳

אפליקציית אימון למבחן במדעים, בלי עלילה. היא בנויה על שיטות למידה שנמצאו יעילות במחקר: תרגול בשאלות, חזרה מרווחת על פני כמה ימים, ערבוב נושאים, דוגמה פתורה לפני תרגול עצמאי, ומשוב ענייני אחרי כל תשובה.

הכתובת: `https://lmoshik-art.github.io/Kefel-lenny/detective/`

## איך זה עובד

- **אימון יומי של כ-10 דקות:** שתי שאלות חימום מנושא חזק, עד שלושה נושאים חדשים (כל אחד עם הסבר ודוגמה פתורה), ושאלות חזרה מעורבבות.
- **חזרה מרווחת:** לכל נושא יש ״קופסה״. תשובה נכונה מרחיקה את החזרה הבאה (יום, יומיים, שלושה, חמישה), וטעות מחזירה את הנושא למחר. כל נושא חוזר לפחות פעם אחת לפני יום המבחן.
- **רמת קושי מסתגלת:** שתי תשובות נכונות ברצף מעלות רמה, וטעות מורידה רמה.
- **״בטוח״ או ״לא בטוח״:** לפני כל בדיקה. בסיכום רואים כמה פעמים התשובה הייתה נכונה גם בלי ביטחון, וטעויות בביטחון חוזרות לתרגול.
- **טעות:** רמז וניסיון נוסף, אחריהם פתרון צעד אחר צעד, ושאלה דומה חוזרת בהמשך האימון.
- **סימולציית מבחן:** 18 שאלות מכל הנושאים, בלי רמזים, עם תוצאה לפי נושא.
- **התקדמות ושיתוף:** מוכנות לפי נושא, ימי אימון, ודוח קצר לשליחה בוואטסאפ או במייל.

## התוכן

כל החומר נמצא ב-`public/content/content.json`, ונכתב לפי חומרי הכיתה: רשימת הנושאים של המורה, סיכומי יחידות המידה והרכב האוויר, המצגות ״גוף וחומר״, ״נפח״ ו״תכונות הגזים באוויר״, ודף העבודה במסה.

בשאלות ההמרה, שאלות המאזניים, כלי המדידה ונפח התיבה, המספרים נוצרים מחדש בכל פעם. כך החזרה בודקת הבנה ולא זיכרון של תשובה.

טעויות שנמצאו בחומרי הכיתה, והערך שבו משתמשת האפליקציה:
- בטבלת הנפח מופיע 0.2 מ״ל = 0.02 ליטר. הנכון הוא 0.0002 ליטר.
- בטבלת הגזים החמצן מסומן ״קל מהאוויר״, ובשקף מאוחר יותר ״מעט כבד מהאוויר״. הנכון: מעט כבד.
- אחוז הפחמן הדו-חמצני מופיע כ-0.03% וכ-0.04%. בשימוש: 0.04%.

## הפעלה ועדכון

```bash
cd detective-lab
npm install
npm run dev        # שרת פיתוח
npm run validate   # בדיקת התוכן והמחוללים
npm run build      # בדיקה ובנייה
```

הבדיקה האוטומטית מוודאת שלכל שאלה יש נושא, שהתשובות במאזניים, בכלי המדידה ובתיבה תואמות לשרטוט, שכל המרה נכונה, ושאין מונחים מחוץ לחומר או מקפים ארוכים. היא מריצה כל מחולל מאות פעמים.
