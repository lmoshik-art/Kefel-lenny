# תיק החקירה: תעלומת המעבדה

אפליקציית לימוד בעברית לתלמיד כיתה ז׳, לקראת בוחן במדעים. המשחק בנוי בסגנון בלשי של פילם נואר, ופתרון המשימות המדעיות מקדם את התעלומה.

התוכן מוגבל לחמשת הנושאים שמסר המורה:

1. גוף וחומר.
2. מסה ומדידת מסה.
3. נפח ומדידת נפח.
4. יחידות מידה והמרות (קילוגרם וגרם, ליטר ומיליליטר בלבד).
5. הרכב הגזים באוויר.

מעבדות המסה, הנפח והפד״ח אינן מוצגות כרגע לתלמיד, ואינן נכללות בתרגול, בציון או בבוחן המסכם. המקום שלהן שמור בקובץ התוכן, וניתן להוסיף אותן בכל עת (ראו "השלמת אזור מעבדה").

## הפעלה

הכתובת לאחר מיזוג לענף main: `https://lmoshik-art.github.io/Kefel-lenny/detective/`

הפעלה מקומית (נדרש Node 20 ומעלה):

```bash
cd detective-lab
npm install
npm run dev        # שרת פיתוח, הכתובת מוצגת במסוף
npm run build      # בדיקת התוכן ובנייה לתיקיית dist
npm run preview    # תצוגה של הבנייה
npm run validate   # בדיקת התוכן בלבד
```

הפריסה ל-GitHub Pages מתבצעת אוטומטית דרך `.github/workflows/deploy.yml`, יחד עם אפליקציית לוח הכפל, בנתיב המשנה `detective/`.

## מבנה

```
public/content/content.json   כל ההסברים, ההמחשות, המשימות, הרמזים, העלילה והבוחן
public/content/assets.json    הגדרת נכסי Higgsfield האופציונליים
public/assets/higgsfield/     מקום לקבצי התמונות והקליפים
scripts/validate-content.mjs  בדיקה אוטומטית של התוכן לפני כל בנייה
src/                          קוד האפליקציה (React + TypeScript)
```

## עדכון תוכן בלי בנייה מחדש

הקובץ `content.json` נטען בזמן ריצה. אפשר לערוך אותו גם ישירות בענף gh-pages, בנתיב `detective/content/content.json`, והשינוי יופיע בטעינה הבאה. מומלץ לערוך בענף main ולהריץ `npm run validate`, כי הבדיקה מוודאת:

- שכל משימה משויכת לאחד מחמשת הנושאים;
- שסכום המשקולות במאזניים שווה לתשובה;
- שהמפלס בכלי המדידה נופל על שנתה ושווה לתשובה;
- שכל המרה מחושבת נכון, ושיש רק המרות של ק״ג וגרם, ליטר ומ״ל;
- שאין מונחים מחוץ לחומר (צפיפות, לחץ, אטום, משקל וכדומה) ואין מקפים ארוכים;
- שאזורי המעבדה שעדיין לא הושלמו ריקים.

### השלמת אזור מעבדה

בכל אחד מהתיקים 2, 3 ו-5 יש שדה `lab` במצב `"pending"`, ובמצב זה הוא מוסתר לגמרי מהתלמיד. אחרי שהחומר מהמחברת יתקבל, יש לשנות את `status` ל-`"ready"` ולכתוב ב-`text` את התוכן המאומת, והאזור יופיע במסך ההסבר של התיק. משימות על המעבדה יתווספו כמשימות רגילות בתיק, רק על בסיס מה שמופיע במחברת.

### נכסי Higgsfield

כשמוסיפים קובץ לתיקייה `public/assets/higgsfield/`, יש לכתוב את הנתיב שלו בשדה `src` המתאים ב-`assets.json`, למשל `"assets/higgsfield/office.jpg"`. כל עוד השדה ריק, או שהקובץ לא נטען, מוצגת חלופה מקומית שנבנתה בקוד. הפרומפטים נמצאים בקובץ `HIGGSFIELD.md`.

## פרטיות ונגישות

- אין הרשמה ואין איסוף של שם, גיל, פרטי קשר או מידע אישי.
- ההתקדמות נשמרת רק ב-localStorage של המכשיר, ובהגדרות יש כפתור איפוס.
- תצוגה בהירה, הפחתת תנועה, צלילים וגשם ברקע (כבויים כברירת מחדל) ודילוג על קטעי עלילה.
- כל פעולה אפשרית בלחיצה או במקלדת, בלי גרירה. אין הגבלת זמן.
