# לוח הכפל שלי

אפליקציית PWA בעברית ללימוד לוח הכפל, בנויה ב-React + Vite + TypeScript, עובדת גם ללא אינטרנט
ונפתחת באייפון במסך מלא דרך "הוסף למסך הבית" בספארי. כל הנתונים נשמרים ב-localStorage במכשיר,
בלי שרת ובלי התחברות.

## הפעלה מקומית

```bash
npm install
npm run dev      # שרת פיתוח
npm run build    # בנייה לייצור לתיקיית dist
npm run preview  # תצוגה מקומית של הבנייה
```

## נכסים גרפיים

הנכסים נמצאים ב-`public/assets` (21 קבצים) ומהם נגזרים אייקוני ה-PWA שבתיקיית `public`:
`apple-touch-icon.png` בגודל 180x180, `icon-192.png` ו-`icon-512.png`.

כדי להוריד את הנכסים המקוריים מהשרת ולייצר מהם מחדש את האייקונים:

```bash
npm run fetch-assets
```

הסקריפט קורא את מיפוי השמות מ-`scripts/assets.txt`, מוודא שכל קובץ ירד בהצלחה ושהוא קובץ PNG
גדול מארבעה קילובייטים, ואז מריץ את `scripts/make-icons.py` שחותך את שלושת האייקונים מתוך
`coin.png` (דורש Pillow: `pip install pillow`).

הערה חשובה: הסביבה שבה נבנה הפרויקט חסמה גישת רשת אל דומיין הנכסים, ולכן הקבצים שבמאגר כרגע הם
נכסים חלופיים זמניים שנוצרו על ידי `scripts/make-placeholders.py` באותם שמות ובאותו סגנון צבעים.
הרצת `npm run fetch-assets` ממחשב עם גישה לדומיין דורסת אותם בקבצים המקוריים, בלי שום שינוי בקוד.

## פריסה עם HTTPS

התקנת PWA באייפון דורשת HTTPS. שרת מקומי או כתובת IP לא יאפשרו התקנה תקינה, ולכן יש לפרוס לאחת
מהאפשרויות הבאות. שתיהן מספקות תעודת HTTPS אוטומטית.

### Vercel

1. להעלות את המאגר ל-GitHub.
2. באתר vercel.com לבחור New Project ולייבא את המאגר.
3. Framework Preset: Vite. פקודת בנייה: `npm run build`. תיקיית פלט: `dist`.
4. ללחוץ Deploy ולקבל כתובת בפורמט `https://<שם-הפרויקט>.vercel.app`.

לחלופין, דרך שורת הפקודה:

```bash
npm install -g vercel
vercel --prod
```

### Netlify

1. באתר netlify.com לבחור Add new site ולחבר את המאגר.
2. פקודת בנייה: `npm run build`. תיקיית פרסום: `dist`.
3. ללחוץ Deploy site ולקבל כתובת בפורמט `https://<שם-האתר>.netlify.app`.

לחלופין:

```bash
npm install -g netlify-cli
npm run build
netlify deploy --prod --dir=dist
```

## הוספה למסך הבית באייפון

1. לפתוח את כתובת ה-HTTPS של האתר בדפדפן Safari (לא בכרום ולא מתוך אפליקציה אחרת).
2. ללחוץ על כפתור השיתוף, הריבוע עם החץ כלפי מעלה, בתחתית המסך.
3. לגלול ולבחור "הוסף למסך הבית", ואז ללחוץ "הוסף".
4. לפתוח את האפליקציה מהאייקון החדש במסך הבית. היא נפתחת במסך מלא, בלי סרגל הכתובת.
5. אחרי הפתיחה הראשונה, כשהאפליקציה טעונה במלואה, היא עובדת גם במצב טיסה וללא אינטרנט.

## מסך ההורים

הכניסה למסך ההורים היא בלחיצה ארוכה של כשנייה וחצי על כפתור גלגל השיניים הקטן בפינת מסך הבית,
ואחריה הקשת קוד בן ארבע ספרות. קוד ברירת המחדל הוא 2580, וניתן לשנות אותו בקבוע `PARENT_CODE`
בקובץ `src/screens/ParentScreen.tsx`.

במסך ההורים אפשר להוסיף ולהפחית כסף ידנית, לקבוע את הסכום שנוסף על כל הישג, לאשר ידנית שטבלה
נלמדה, לשנות את שם הילדה, לאשר סופית את פתיחת הכספת ולאפס את כל הנתונים.

## מנגנון הלמידה והחיסכון

- כל סבב תרגול הוא חמש שאלות בלבד, ואחריו חגיגה קצרה. אין טיימר ואין עונשים.
- תשובה שגויה מקבלת עידוד עדין והצגת התרגיל המלא עם התשובה הנכונה.
- תרגיל שטועים בו חוזר בסבבים הבאים עד שתי תשובות נכונות ברצף.
- תשובה נכונה תוך פחות מארבע שניות מזכה בכוכב בונוס, כדי לעודד שליפה מהזיכרון.
- טבלה מסומנת כנלמדה רק אחרי מעבר מבחן האלוף בציון מלא, חמש מתוך חמש, בשני ימים שונים,
  או באישור ידני של ההורה במסך ההורים.
- על כל מעבר של מבחן האלוף נוסף לחיסכון הסכום שההורה קבע, ברירת המחדל חמישה שקלים.
- הכסף מוצג כנעול בכספת. הוא נפתח רק כאשר מתקיימים שני התנאים יחד: הגעה ל-300 שקלים וסימון כל
  הטבלאות 2 עד 10 כנלמדו. אז נפתח במסך ההורים כפתור האישור הסופי, והכספת נפתחת באנימציה.

## מבנה הקוד

```
src/
  lib/          לוגיקת המצב, האחסון המקומי, הלמידה והצלילים
  components/   רכיבים משותפים: הגיבורה, מד החיסכון, מונה הכוכבים, אנימציות
  screens/      מסכי האפליקציה: פתיחה, בית, היכרות, תרגול, אלוף, חיסכון, הורים
scripts/        הורדת הנכסים, יצירת האייקונים, יצירת נכסים חלופיים
```

## נתונים שנשמרים במכשיר

שם הילדה, מספר הכוכבים, הסכום שנצבר, הסכום לכל הישג, מצב הכספת, נתוני כל טבלה (היכרות, ציון
מיטבי, ימי מעבר מבחן האלוף, אישור הורה) והתקדמות ברמת התרגיל הבודד. המפתח הוא
`kefel-lenny-state-v1`.
